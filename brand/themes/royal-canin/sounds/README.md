# Brand sounds (shared across game types)

Royal Canin bindings:

| Key | File | Trigger |
|-----|------|---------|
| `button` | `Cooking_Game_UI_Menu_Click_01.wav` | UI taps |
| `countdown` | `3 2 1 go sound effect editted.wav` | Game countdown starts |
| `complete` | `Slot Machine Mega Win_Cutted.wav` | Puzzle won |
| `menuBgm` | `Ilona Harpaz - Merry-Go-Round.wav` | Menu / flow pages |
| `gameBgm` | `Ilona Harpaz - Merry-Go-Round.wav` | Gameplay |

Configured in `src/brand/themes/royal-canin.json`.
